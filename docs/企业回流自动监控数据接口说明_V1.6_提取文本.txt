1.1.3 获取accessToken方式
1. 登录《重点排污单位自动监控与基础数据库 系统（企业服务端）》进行
数据接口授权，生成服务申请码；
2. 登录《重点排污单位自动监控与基础数据库 系统（企业服务端）》进行数据接口授权，申
请数据回流账号，通过1.3和1.4接口获得accessToken；
1.2 接口访问地址
http://ip:端口/amOnline/app/was/baseroute/requestRoute!databack.page

请求方式:POST
请求数据类型:application/x-www-form-urlencoded
请求参数:
schema

sign 签名 query true string
authId 帐号id(企业服务端回流接口授权生成) query true string
method auth/pubilc-key query true string
响应参数:
schema
code 200成功 500失败 string
data 公钥 string string
msg 调用成功/调用失败 string
